Questions about BASE

When does BASE release?

BASE releases on 1 October 2026. Join the email list before then and you'll get an early bird code for $30 off, plus first access on launch day.

What do I need to run it?

Gym access and the ability to already squat, hinge and press. BASE is not a beginner program, it assumes you've got the fundamentals and want a real off-season plan built on top of them.

How is it delivered?

Through TrainHeroic, the gold-standard training app. Every session is written end to end with video demonstrations, coaching cues, weight tracking and your testing data all in one place.

How much time per week?

Five sessions: three gym, one engine (conditioning) and one speed. It's structured to build you without burning you out across the off-season.

Is this coaching?

BASE is a structured program, not 1:1 coaching. It's the option for athletes who want a Primed Performance program but aren't ready to commit to full online coaching. If you want individual coaching, that's on the coaching page.

Do I keep it?

Yes. BASE is a one-off purchase. Run it this off-season, then run it back next year.
